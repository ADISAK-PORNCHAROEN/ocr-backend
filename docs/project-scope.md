# ขอบเขต OCR Playground

สถานะ: ขอบเขตที่ตกลงกันสำหรับเวอร์ชันแรก ยังไม่ได้พัฒนา

## เป้าหมาย

สร้างโปรเจกต์ portfolio เพื่อทดลองถอดข้อความจากเอกสารตัวพิมพ์ภาษาไทยและอังกฤษด้วย OpenThai OCR Text บน CPU ใช้งานและสาธิตบนเครื่องตัวเองก่อน ดูรายละเอียดโมเดลที่ [OpenThai OCR](https://iapp.co.th/openmodels/openthai-ocr)

## ความสามารถ

- รับ JPG, PNG หรือ PDF ครั้งละหนึ่งไฟล์ โดย PDF มีหลายหน้าได้
- ตรวจชนิดและเนื้อหาไฟล์ ขนาดไฟล์ จำนวนหน้า และปฏิเสธ PDF ที่มีรหัสผ่านหรือไฟล์ที่เปิดไม่ได้
- ประมวลผลทุกหน้า แสดงความคืบหน้ารวมทั้งหน้าที่ล้มเหลว และแสดงผลแยกตามหน้า
- แสดงหน้าต้นฉบับคู่กับข้อความ ผู้ใช้แก้ไขข้อความทั้งหน้า คัดลอก หรือคืนค่าผล OCR เดิมของหน้าปัจจุบันได้ โดยยืนยันก่อนคืนค่า
- จำข้อความที่แก้ขณะสลับหน้าใน session ปัจจุบัน เมื่อรีเฟรชหรือปิดหน้าให้เริ่มใหม่
- หน้าที่อ่านแล้วไม่พบข้อความถือว่าสำเร็จ และผู้ใช้เพิ่มข้อความเองได้
- หากบางหน้าล้มเหลว ให้แสดงและดาวน์โหลดหน้าที่สำเร็จ พร้อมแจ้งผลไม่ครบ หากต้องการลองใหม่ให้อัปโหลดไฟล์อีกครั้ง
- ดาวน์โหลด TXT รวมทุกหน้าโดยคั่นเลขหน้า และ JSON ที่แยกข้อความแก้ไขจากผล OCR เดิม รวมตำแหน่งและความมั่นใจของผลเดิม
- ไม่มีบัญชีผู้ใช้และไม่มีการเก็บข้อมูลถาวร ลบข้อมูลชั่วคราวเมื่อจบงานอย่างชัดเจน และลบข้อมูลที่หมดอายุเป็นกลไกสำรอง

## สิ่งที่ยังไม่รวม

การอัปโหลดหลายไฟล์ การเลือกประมวลผลบางหน้า การยกเลิกหรือลองใหม่เฉพาะหน้า การแสดงกรอบหรือค่าความมั่นใจบนหน้าจอ การเปิด PDF ด้วยรหัสผ่าน การรักษาตารางด้วย OCR Markdown และประวัติงาน

## ประเด็นที่ต้องตรวจสอบก่อนพัฒนา

- ทดลองโมเดลกับเอกสารจริงและตรวจรูปแบบผลลัพธ์ พิกัด และค่าความมั่นใจ
- ทดสอบการแปลงหน้า PDF เป็นภาพและให้พิกัดตรงกับภาพที่แสดง
- วัดบนเครื่องเป้าหมายก่อนกำหนดขนาดไฟล์ จำนวนหน้าสูงสุด และอายุข้อมูลชั่วคราว
- ตรวจการจัดการข้อมูลและการลบไฟล์ รวมถึงกรณีปิดหน้าโดยไม่ได้ส่งคำขอลบ
